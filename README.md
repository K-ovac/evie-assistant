# Иви — локальный голосовой ассистент

Голосовой ассистент, который целиком работает на твоём компьютере: слушает микрофон, понимает речь, думает через локальную LLM, умеет выполнять действия на компьютере и ходить в интернет, отвечает голосом. С ней можно говорить вживую (без нажатия кнопок) или писать через Telegram-бота.

## Возможности

- **Живой диалог.** Микрофон слушается постоянно, конец фразы определяется по паузе (Silero VAD). Можно говорить с обращением по имени («Иви, …») или без него.
- **Режим диалога.** После ответа некоторое время имя говорить не нужно. Потом она снова ждёт обращения.
- **Перебивание.** В наушниках можно перебить её голосом (опционально).
- **Инструменты (function calling).** Модель сама решает, что вызвать: терминал, почта, приложения, мониторинг системы, погода, поиск в интернете и т.д.
- **Подтверждение опасных действий.** Команды вне белого списка выполняются только после «да» голосом (или нажатия кнопки в Telegram).
- **Нормальная озвучка.** Цифры, проценты, единицы измерения и английские аббревиатуры превращаются в русские слова, длинные ответы режутся на части.
- **Telegram-бот.** Текст и голосовые сообщения, та же логика и те же инструменты.

## Как это работает

```
Микрофон → Silero VAD (конец фразы) → Whisper (речь → текст)
        → LLM в LM Studio ⇄ инструменты (agent_tools.py)
        → нормализация текста → Silero TTS → колонки
```

## Структура проекта

```
scripts/
├── main.py                  # голосовой режим: основной цикл
├── telegram_bot.py          # режим Telegram
├── data/
│   ├── config.py            # все настройки
│   └── system_prompt.txt    # системный промпт (читается при каждом запросе)
├── log/
│   └── logger_setup.py      # логирование в консоль и log/assistant.log
└── handlers/
    ├── audio_handler.py     # микрофон, VAD, воспроизведение
    ├── stt_handler.py       # Whisper
    ├── llm_handler.py       # общение с LM Studio, цикл вызова инструментов
    ├── agent_tools.py       # инструменты ассистента
    ├── tts_handler.py       # Silero TTS (с нарезкой длинного текста)
    ├── text_normalizer.py   # цифры, символы, латиница → русские слова
    └── farewell.py          # распознавание прощания
```

## Требования

- Linux с графической сессией (для запуска окон и программ), Python 3.12
- [LM Studio](https://lmstudio.ai) с запущенным локальным сервером и моделью, которая **поддерживает tool use** (в списке моделей есть метка Tool Use; например, семейства Qwen, Llama 3.1+, Mistral)
- Микрофон и колонки/наушники

## Установка

1. Системные пакеты (Debian/Ubuntu/Mint):

   ```bash
   sudo apt install ffmpeg libportaudio2 libsndfile1 xdg-utils btop
   ```

2. Виртуальное окружение и зависимости:

   ```bash
   python3 -m venv myenv
   source myenv/bin/activate
   pip install -r requirements.txt
   ```

   Если видеокарты под CUDA нет, torch можно поставить облегчённым:

   ```bash
   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
   pip install -r requirements.txt
   ```

3. LM Studio: загрузи модель с поддержкой tool use и запусти локальный сервер (по умолчанию `http://127.0.0.1:1234`).

4. Создай каталоги `data/` и `log/`, если их нет, и заполни `data/config.py` (см. ниже).

При первом запуске модели Whisper и Silero скачиваются из интернета и кэшируются (`~/.cache/whisper`, `~/.cache/torch/hub`).

## Настройка (`data/config.py`)

Секреты лучше хранить в переменных окружения, а не в коде.

| Параметр | Назначение |
|---|---|
| `AI_NAME` | Имя ассистента («Иви») |
| `WHISPER_MODEL`, `WHISPER_LANGUAGE` | Модель Whisper (`small`, `base`, …) и язык (`ru`) |
| `LM_STUDIO_URL`, `LM_MODEL` | Адрес сервера LM Studio и имя модели |
| `MAX_TOOL_STEPS` | Сколько вызовов инструментов подряд допустимо за один ответ |
| `SYSTEM_PROMPT_FILE` | Путь к файлу системного промпта |
| `SILERO_SPEAKER`, `SILERO_SAMPLE_RATE`, `OUTPUT_FILE` | Голос (`baya`, `kseniya`, `xenia`, `aidar`, `eugene`), частота, временный файл озвучки |
| `INPUT_DEVICE` | Микрофон (`None` — системный; список: `audio_handler.list_devices()`) |
| `VAD_THRESHOLD` | Чувствительность к речи (0.5; выше — меньше ложных срабатываний) |
| `SILENCE_END_SEC` | Пауза, после которой фраза считается законченной (0.8) |
| `MIN_SPEECH_SEC`, `MAX_UTTERANCE_SEC`, `PRE_ROLL_SEC` | Минимальная и максимальная длина фразы, запас перед началом речи |
| `USE_WAKE_WORD`, `WAKE_WORDS` | Режим обращения по имени и варианты, как Whisper может расслышать имя |
| `CONVERSATION_TIMEOUT` | Сколько секунд после ответа имя говорить не нужно (рекомендуется 60–120) |
| `BARGE_IN`, `BARGE_IN_THRESHOLD` | Перебивание голосом (**только в наушниках**) |
| `DEFAULT_CITY` | Город по умолчанию для погоды |
| `EMAIL_IMAP_HOST`, `EMAIL_USER`, `EMAIL_PASSWORD` | Почта (IMAP, пароль приложения, не основной) |
| `TG_BOT_TOKEN`, `TG_ALLOWED_IDS`, `TG_PROXY` | Telegram: токен, список разрешённых id, прокси (например `socks5://127.0.0.1:1080`) |

Секреты через окружение:

```bash
export EMAIL_USER="..."
export EMAIL_PASSWORD="..."
export TG_BOT_TOKEN="..."
export TG_ALLOWED_IDS="123456789"
```

## Запуск

Голосовой режим:

```bash
cd scripts
source myenv/bin/activate
python3 main.py
```

Скажи «Иви, привет». Выход: фраза «пока», «до свидания», «отключись» в конце реплики или `Ctrl+C`. Не используй `Ctrl+Z`: он только приостанавливает процесс, и микрофон остаётся занятым.

Telegram-бот (отдельный процесс, можно параллельно с голосовым режимом):

```bash
python3 telegram_bot.py
```

Токен получи у @BotFather. Чтобы узнать свой id, запусти бота с пустым `TG_ALLOWED_IDS`, напиши ему `/start`, и вставь полученный id в переменную. Пока список пуст, бот никому не отвечает. Команды: `/start`, `/reset` (очистить диалог).

## Инструменты

| Инструмент | Что делает | Подтверждение |
|---|---|---|
| `get_current_time` | Дата и время | нет |
| `get_weather` | Погода и прогноз на 3 дня (Open-Meteo) | нет |
| `web_search` | Поиск в интернете (DuckDuckGo) | нет |
| `read_webpage` | Текст страницы по ссылке | нет |
| `open_url` | Открывает сайт (предварительно проверяет, что он существует) | нет |
| `open_app` | Запуск приложений из списка `APPS` | нет |
| `open_terminal`, `open_system_monitor` | Окно терминала, btop/htop или графический монитор | нет |
| `get_system_stats` | Нагрузка CPU, память, диск, температура | нет |
| `check_email` | Непрочитанные письма (только чтение) | нет |
| `add_note`, `read_notes` | Заметки в `data/notes.txt` | нет |
| `run_command` | Команда в терминале | да, кроме простых из белого списка (`ls`, `df`, `uptime`…) |

### Как добавить свой инструмент

В `handlers/agent_tools.py`:

```python
@tool(
    "Что делает и КОГДА использовать",                       # описание для модели
    properties={"name": {"type": "string", "description": "..."}},
    required=["name"],
    confirm=False,                                           # True или функция args -> bool
)
def my_tool(name):                                           # имя функции = имя инструмента
    return "короткий текстовый результат"
```

Правила:
- Описание важнее кода: по нему модель решает, вызывать ли инструмент.
- Всегда возвращай короткую строку: её читает модель и по ней отвечает голосом.
- Ключи в `properties` совпадают с параметрами функции.
- Для запуска графических программ используй `Popen` с `start_new_session=True`, а не `subprocess.run`.
- Всему, что удаляет, отправляет или меняет что-то, ставь `confirm=True`.

Проверить инструмент без голоса и LLM (из папки `scripts/`):

```bash
python3 -c "from handlers import agent_tools as t; print(t.execute('get_system_stats', {}, lambda d: True))"
```

## Системный промпт

Лежит в `data/system_prompt.txt` и перечитывается при каждом запросе, поэтому его можно править не перезапуская ассистента. Что стоит в нём держать:
- коротко, 1–3 предложения, без markdown, списков и эмодзи (это голос);
- при просьбе что-то сделать сразу вызывать инструмент, не обещая и не спрашивая разрешения (подтверждение запросит система);
- называть действие выполненным только после успешного результата инструмента;
- для данных использовать `get_weather` и `web_search`, сайты открывать только по прямой просьбе.

## Безопасность

- `run_command` даёт доступ к терминалу. Не отключай подтверждения.
- В Telegram отвечай только своим id (`TG_ALLOWED_IDS`). Токен и пароль почты держи в переменных окружения.
- Текст из интернета недоверенный: `read_webpage` не ходит в локальную сеть, а результаты помечены как недоверенные. Всё равно не давай модели инструментов, которые необратимо что-то удаляют или отправляют, без `confirm=True`.
- Голосовое подтверждение может ошибочно сработать от чужого голоса или телевизора. Для особо опасных действий лучше подтверждение через консоль или кнопки в Telegram.
- Перебивание (`BARGE_IN`) включай только в наушниках, иначе она будет слышать саму себя.

## Решение проблем

| Проблема | Что делать |
|---|---|
| Распознаёт, но не отвечает | Включён режим обращения по имени: говори «Иви, …» или поставь `USE_WAKE_WORD = False`. Если имя не распознаётся, добавь варианты в `WAKE_WORDS`. |
| Перестаёт отвечать через полминуты | Увеличь `CONVERSATION_TIMEOUT` до 60–120. |
| Обрывает на полуслове | Увеличь `SILENCE_END_SEC` до 1.0–1.2. |
| Реагирует на фоновые звуки | Подними `VAD_THRESHOLD` до 0.6–0.7. |
| Модель не вызывает инструменты | Нужна модель с поддержкой tool use. Проверь формулировки описаний инструментов и системный промпт. |
| Не открываются окна и программы | Запускай из графической сессии (терминал на рабочем столе): без `DISPLAY` / `WAYLAND_DISPLAY` окна не появятся. |
| Цифры или аббревиатуры не озвучиваются или звучат странно | Дополни словари `WORDS` и `UNITS` в `handlers/text_normalizer.py`. |
| Микрофон не открывается на 16 кГц | Код сам переключится на родную частоту. Если не помогло, выбери устройство через `INPUT_DEVICE`. |
| Telegram недоступен | Укажи `TG_PROXY`. Нужен пакет `python-telegram-bot[socks]` для `socks5://`. |
| Whisper «слышит» фразы в тишине | Это его галлюцинации на шуме. Типичные уже фильтруются в `stt_handler.py`, новые добавляй в `HALLUCINATIONS`. |
| `ModuleNotFoundError` / конфликт имён модулей | Запускай из папки `scripts/` и импортируй модули через `handlers.…`. |

## Логи
